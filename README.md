# splunk-lab-dashboards
Home lab dashboards for Splunk Enterprise integrating FortiGate syslog, Windows telemetry (Event Logs/Perfmon), and AWS data sources.
## FortiGate Network Security Dashboard

![FortiGate Dashboard](FortiGate%20Network%20Security.png)

A Splunk dashboard for monitoring FortiGate firewall activity in real time, including traffic volume, blocked vs. allowed connections, threat detection, top services, bandwidth usage, and geographic traffic destinations. Built as part of a home lab integrating FortiGate syslog data into Splunk Enterprise.
